# UI kit — app Rotaviva

Blocos em `RotavivaComponents.jsx`: `AppHeader`, `BalanceCard`, `TripRow`, `ShortcutGrid`, `BottomNav`. Telas em `Screens.jsx`: `HomeScreen` (header + saldo + atalhos + últimas viagens + nav) e `RechargeScreen` (valor + método + confirmar). O fluxo navegável é Início → Recarregar → Confirmação.
