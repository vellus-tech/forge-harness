# Hard nos

- Nunca desenhar o símbolo Rotaviva em SVG — use sempre os PNGs de `assets/brand/`.
- Nunca usar a cor de marca em texto corrido pequeno (contraste ~3.4:1 sobre branco).
- Nunca remover o anel de foco.

# Voz (cheat-sheet)

"Recarregar", não "efetuar recarga". "Suas viagens", não "histórico de transações".
