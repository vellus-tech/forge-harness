# Linguagem Ubíqua

## Validação
- **Embarque:** passagem do passageiro pelo validador, aceita ou recusada.
- **Janela de Integração:** 60 minutos após o primeiro embarque pago em que a segunda linha não cobra tarifa cheia.

## Carteira
- **Saldo:** valor pré-pago disponível, em centavos.
- **Movimentação:** débito ou crédito imutável no saldo.

## Recarga
- **Recarga:** pedido de crédito pago via Pix.
