## O mecanismo, em uma frase

## O predicado, para vocês medirem as suas

```python
import hashlib, os, sys
forge = os.path.join(sys.argv[1], '.forge')
lock  = os.path.join(forge, 'cache', 'machinery.lock')
ENRICH = ('agents/', 'rules/', 'skills/')
ok = enr = maq = miss = 0; alvo = []
for line in open(lock, encoding='utf-8'):
    line = line.rstrip('\n')
    if not line or line.startswith('#'): continue
    p = line.split(None, 1)
    if len(p) != 2: continue
    sha, path = p[0], p[1].strip()
    full = os.path.join(forge, path)
    if not os.path.isfile(full): miss += 1; continue
    if hashlib.sha256(open(full,'rb').read()).hexdigest() == sha: ok += 1
    elif path.startswith(ENRICH): enr += 1
    else: maq += 1; alvo.append(path)
print(f"intocados={ok} enriquecivel={enr} MAQUINARIA={maq} ausentes={miss}")
for a in sorted(alvo): print(" ", a)
```

**Duas armadilhas** que valem mais que o script. Primeira: o lock mora em `.forge/cache/machinery.lock`, não em `.forge/machinery.lock` — eu concluí "não existe" olhando o caminho errado, e foi assim que este achado quase não aconteceu. Segunda: se o lock **não existir** na sua árvore, isso não é zero divergentes, é **não medido**. Uma árvore sem lock não é segura, é não medida — e aprovar por ausência de registro é a vacuidade que este detector existe para evitar.

## O que eu recomendo, e o que estou construindo

Congelar o upgrade custa **zero hoje**: o pacote publicado e o repo-fonte estão ambos em `0.10.0`, que é a versão já aplicada — não há upgrade pendente para adiar.

Mas decisão não é mecanismo, e enquanto depender de alguém lembrar, ele volta. Estou construindo aqui uma guarda que reprova o comando quando há maquinaria divergente, listando os arquivos: um detector em `.forge/scripts/` mais um hook `PreToolUse`. Os dois têm nome novo, então não estão no lock e sobrevivem ao próprio overlay que detectam — e a fiação mora no `.claude/settings.json`, que também não está no lock. Publico quando estiver com o mutante provado.
