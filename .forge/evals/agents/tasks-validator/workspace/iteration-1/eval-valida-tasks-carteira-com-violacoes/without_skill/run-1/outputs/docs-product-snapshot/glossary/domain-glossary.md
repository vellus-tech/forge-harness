# Glossário de domínio — Embarque Fácil

| Termo | Definição |
|---|---|
| Carteira | Conta pré-paga do passageiro vinculada ao cartão de transporte; guarda o saldo em centavos. |
| Recarga | Crédito de saldo na carteira a partir de um pagamento Pix confirmado (identificado pelo `txid`). |
| Débito de embarque | Desconto da tarifa no saldo no momento em que o validador aprova o embarque. |
| Integração temporal | Desconto na segunda viagem dentro da janela de 90 minutos. |
| Operadora | Empresa de ônibus do consórcio; é o tenant do sistema. |
| Validador | Equipamento embarcado no ônibus que lê o cartão e decide o embarque. |
