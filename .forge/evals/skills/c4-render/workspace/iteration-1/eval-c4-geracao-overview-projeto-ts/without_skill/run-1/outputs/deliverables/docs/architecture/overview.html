Pagamentos Core — Mapa de arquitetura (C4)

Gerado a partir da inspeção do código em src/ (módulos billing, ledger, notifications, shared). Abra este arquivo em qualquer navegador para navegar entre os três níveis.


    
Visão de contexto: quem usa o Pagamentos Core e com quais sistemas externos ele troca dados (adquirente de pagamentos e provedor de e-mail).

  

  

    

    
Visão de containers: hoje o projeto é um único serviço Node.js/TypeScript que concentra os módulos de billing, ledger e notifications — não há separação em serviços independentes no código atual.

  

  

    

    
Visão de componentes: os quatro módulos encontrados em src/ e suas dependências internas, mais a saída externa de e-mail feita por notifications.
