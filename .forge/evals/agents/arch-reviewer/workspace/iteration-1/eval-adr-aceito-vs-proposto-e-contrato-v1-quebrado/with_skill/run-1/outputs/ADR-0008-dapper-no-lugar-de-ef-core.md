# ADR-0008 — Dapper no lugar de EF Core na persistência

- Status: Proposto
- Data: 2026-09-02

## Contexto

Discussão em aberto no chapter de backend sobre trocar EF Core por Dapper por desempenho. Ainda sem votação.

## Decisão proposta

Se aceita, novos repositórios usariam Dapper e EF Core deixaria de ser adicionado a projetos Infrastructure.
