# Glossário de Domínio (termos gerais)

| Termo | Definição |
|---|---|
| Passageiro | Usuário final portador de cartão físico ou virtual |
| Operadora | Empresa de ônibus dona de uma ou mais linhas (Viação Serrana, Expresso Vale, TransSereno) |
| Consórcio | Entidade que coordena as operadoras e apura o repasse |
| Validador embarcado | Equipamento físico no ônibus que decide o embarque, opera offline |
