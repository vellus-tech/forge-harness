# Rotaviva — contexto de marca

Rotaviva é uma carteira de mobilidade urbana: o passageiro recarrega o passe de transporte, acompanha o extrato de viagens e usa atalhos (recarga, cartões, ajuda).

## Fundamentos visuais

Cor de marca verde-petróleo (`--brand`), neutros frios, grade de espaçamento de 4 pt, raios generosos em cards, sombras suaves. Tipografia display Sora, UI Manrope, ambas via Google Fonts (este handoff não traz fontes self-hosted). Apenas tema claro nesta versão.

## Voz

Direta, próxima, sem jargão bancário. Frases curtas. Valores sempre com "R$" e vírgula decimal.
