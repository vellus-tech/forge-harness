# Bounded Context — Validação

**Objetivo:** decidir o embarque e calcular a tarifa com integração temporal.

**Linguagem:** Embarque, Integração Temporal, Janela de Integração, Tarifa Aplicada.

**Ownership:** schema `validacao` (tabelas `embarque`, `janela_integracao`).

**Eventos publicados:** `EmbarqueRegistrado` v1 (Published Language).

**Fora de escopo:** saldo do passageiro (Carteira).
