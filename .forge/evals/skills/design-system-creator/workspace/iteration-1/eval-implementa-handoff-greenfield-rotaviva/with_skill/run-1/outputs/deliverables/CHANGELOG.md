# Changelog

Todas as mudanças notáveis deste projeto são documentadas neste arquivo.

## [Não lançado]

### Adicionado

- `packages/design-tokens` — tokens de marca, neutros, semânticas, tipografia (Sora/Manrope), espaçamento 4pt, raios e sombras, espelhados de `colors_and_type.css` do handoff Claude Design (`rotaviva-design-system`).
- `packages/icons` — wrapper `Icon` sobre `lucide-react` e `RotavivaMark` (PNG real, variantes teal/black/white).
- `packages/ui-components` — primitivos `Button`, `Input`, `Badge`, `Card`, `Eyebrow`; blocos `AppHeader`, `BalanceCard`, `TripRow`, `ShortcutGrid`, `BottomNav`; padrões só-Storybook `PhoneFrame`, `HomeScreen`, `RechargeScreen` e o fluxo interativo de recarga.
- Storybook (`@storybook/react-vite` + `addon-a11y` + `addon-themes`) com stories de Fundamentos, Componentes, Blocos e Padrões.
- `docs/product/design-system/{design-system,tokens,components,accessibility}.md`.
