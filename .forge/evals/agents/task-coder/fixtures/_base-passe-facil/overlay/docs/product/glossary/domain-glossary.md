# Glossário de domínio — Passe Fácil

| Termo | Definição |
|---|---|
| Centavos | Todo valor monetário é inteiro em centavos de real; nunca ponto flutuante. |
| Carteira | Saldo pré-pago do passageiro, usado para pagar a tarifa no embarque. |
| Tarifa | Valor cobrado por embarque, em centavos. |
| Troco | Diferença entre o valor pago em espécie no guichê e a tarifa, em centavos. |
| Lançamento | Registro de crédito (recarga) ou débito (embarque) no extrato do passageiro. |
